# flagged-board-submit-handoff plugin

Spot a flagged job board and hand off to Abel fast with a cheat sheet.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install flagged-board-submit-handoff@abelprasad
```

The skill itself lives at `skills/made/flagged_board_submit_handoff/` in this repo; this plugin ships the same files so the plugin install is self-contained.
