# repo-packaging plugin

ADRs, CLI product, privacy rule, dev-copy rule, presence. Package a repo like a product.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install repo-packaging@abelprasad
```

The skill itself lives at `skills/made/repo-packaging/` in this repo; this plugin ships the same files so the plugin install is self-contained.
