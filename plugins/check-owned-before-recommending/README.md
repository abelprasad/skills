# check-owned-before-recommending plugin

Check what Abel already owns before recommending a product.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install check-owned-before-recommending@abelprasad
```

The skill itself lives at `skills/made/check_owned_before_recommending/` in this repo; this plugin ships the same files so the plugin install is self-contained.
