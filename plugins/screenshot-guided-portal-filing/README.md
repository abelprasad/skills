# screenshot-guided-portal-filing plugin

File in a blocking portal with screenshots instead of driving it.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install screenshot-guided-portal-filing@abelprasad
```

The skill itself lives at `skills/made/screenshot_guided_portal_filing/` in this repo; this plugin ships the same files so the plugin install is self-contained.
