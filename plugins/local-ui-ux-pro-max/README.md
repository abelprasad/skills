# local-ui-ux-pro-max plugin

Design bundle: shadcn + Tailwind, brand, banners, slides.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install local-ui-ux-pro-max@abelprasad
```

The skill itself lives at `skills/liked/local-ui-ux-pro-max/` in this repo; this plugin ships the same files so the plugin install is self-contained.
