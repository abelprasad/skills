# i-have-adhd plugin

ADHD output protocol: action first, numbered steps, no preamble.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install i-have-adhd@abelprasad
```

The skill itself lives at `skills/liked/i-have-adhd/` in this repo; this plugin ships the same files so the plugin install is self-contained.
