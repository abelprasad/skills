# local-ponytail plugin

Laziest working solution: YAGNI, stdlib first, one line before fifty.

Install inside a Claude Code session:

```
/plugin marketplace add abelprasad/skills
/plugin install local-ponytail@abelprasad
```

The skill itself lives at `skills/made/local-ponytail/` in this repo; this plugin ships the same files so the plugin install is self-contained.
